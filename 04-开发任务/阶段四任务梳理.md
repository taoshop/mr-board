## 10. 阶段四新增技术要点

### 10.1 预计算表设计

```sql
CREATE TABLE report_daily_summary (
    summary_date    DATE NOT NULL,
    project_id      BIGINT,
    created_count   INT DEFAULT 0,
    merged_count    INT DEFAULT 0,
    closed_count    INT DEFAULT 0,
    avg_merge_hours DECIMAL(10,2),
    ci_success_count INT DEFAULT 0,
    ci_failed_count  INT DEFAULT 0,
    conflict_count   INT DEFAULT 0,
    PRIMARY KEY (summary_date, project_id)
);
```

### 10.2 日报预计算 Job 逻辑

```
每日凌晨 2:00 触发
    │
    ▼
统计昨日 00:00 ~ 23:59 的 MR 数据
    ├──→ mrs 表：按 project_id 分组统计 created/merged/closed 数量
    ├──→ mrs 表：计算 merged_at - created_at 的平均值与中位数
    ├──→ ci_jobs 表：统计 success / failed 数量
    └──→ mrs 表：统计 has_conflict = true 的数量
    │
    ▼
写入 report_daily_summary 表（存在则更新）
```

### 10.3 EasyExcel 流式导出要点

- 使用 `EasyExcel.write(response.getOutputStream(), MrExportDTO.class).sheet("MR列表").doWrite(data)`
- 大数据量时分页查询，每批 500 条写入，避免全量加载到内存
- 响应头设置 `Content-Disposition: attachment; filename=mr_export_20260101.xlsx`
