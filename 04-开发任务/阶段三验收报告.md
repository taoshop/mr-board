## 5. 遗留问题与风险

### 5.1 遗留问题清单

| 编号 | 问题描述 | 影响 | 建议处理阶段 |
|---|---|---|---|
| L-3-1 | B-3.3 评论缓存接口未实现 | 详情面板无评论 Tab | 阶段四（如需评论功能） |
| L-3-2 | Webhook / Git API 未在真实环境验证 | 无法确认端到端连通性 | 阶段四（部署测试环境后） |
| L-3-3 | 前端未做 1440×900 响应式专项适配 | 小屏显示可能异常 | 阶段四（UI 优化迭代） |
| L-3-4 | JMeter 压测未执行 | 无性能基线 | 阶段四（性能优化前） |

### 5.2 风险说明

- **R-3-1（Git API 权限）**：代码层面已做 Token 解密与调用，但真实 GitLab/GitHub 实例的 Token 权限、分支保护规则可能导致 merge 失败。**建议阶段四在测试环境验证。**
- **R-3-2（Webhook 时延）**：Webhook 作为即时同步补充，若网络不通则 fallback 到定时同步。**当前已具备 fallback 能力，风险可控。**
