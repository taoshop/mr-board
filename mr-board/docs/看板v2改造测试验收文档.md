## 1. 概述

### 1.1 本次验收范围

本次迭代基于《看板界面优化设计方案》完成看板 v2 改造，核心变更如下：

| 模块 | 变更说明 | 关联文件 |
|------|----------|----------|
| **列结构精简** | 移除「CI 检查中」独立列，CI 降为卡片维度标识 | `BoardController.java` / `DashboardView.vue` |

| **列头图标增强** | 每列配 Element Plus 图标，颜色与列主题一致 | `DashboardView.vue` |
| **拖拽交互优化** | 列高亮颜色语义：绿色=允许、黄色=条件、红色=禁止、灰色=终态；禁止从终态列拖拽 | `DashboardView.vue` |
| **前端筛选对齐** | 状态筛选下拉移除 `ci_checking`，仅保留 6 个有效状态 | `DashboardView.vue` |

## 2. 功能特性验收

### 2.1 列结构：6 列看板（无 CI 检查中）

**需求**: 移除独立的「CI 检查中」列，CI 状态作为卡片上的独立标识展示。

**实现**: 后端 `COLUMNS` 常量、前端 `boardStatus` 常量、筛选下拉均移除 `ci_checking`。

#### 验收点

| # | 验收条件 | 预期结果 | 验证方式 |
|---|----------|----------|----------|
| 2.1.1 | 后端 `/api/board/columns` | 返回 6 列，无 `ci_checking` | API 调用 |
| 2.1.2 | 前端状态筛选下拉 | 仅显示 6 个选项，无「CI 检查中」 | 页面检查 |
| 2.1.3 | 看板页面列头 | 显示 6 列：待 Review / Review 中 / 冲突待解决 / 可合并 / 已合并 / 已关闭 | 截图验证 |
| 2.1.4 | 列统计计数 | 每列统计仅计算对应 6 状态之一 | 代码审查 |

### 2.2 CI 作为独立维度

**需求**: CI 状态不再决定列归属，仅作为卡片上的图标/摘要展示。

**实现**: `BoardStatusCalculator` v2 中，CI running/pending 不返回单独列；CI failed 归入 `conflict` 列并在卡片上展示「CI 失败」标签。

#### 验收点

| # | 验收条件 | 预期结果 | 验证方式 |
|---|----------|----------|----------|
| 2.2.1 | CI running + reviewing | 卡片显示在「Review 中」列，顶部橙色运行图标 | 代码审查 |
| 2.2.2 | CI pending + approved + mergeable | 卡片显示在「可合并」列，顶部灰色等待图标 | 代码审查 |
| 2.2.3 | CI failed + 任意状态 | 卡片显示在「冲突待解决」列，红色「CI 失败」标签 + 红色摘要 | 代码审查 |
| 2.2.4 | CI success | 卡片顶部绿色对勾，摘要区显示「CI 通过」 | 截图验证 |

### 2.3 新卡片布局（MrCard.vue）

**需求**: 按设计方案重新组织卡片信息层级，提升可读性。

**卡片区块**（从上到下）：

1. **头部**: CI 状态点（彩色图标） + 状态标签（el-tag） + MR#（右侧）
2. **Reviewer 行**: Reviewer chip（头像+名字+状态图标），空时显示「未指派 Reviewer」提示
3. **标题**: 2 行截断，悬浮显示完整标题
4. **伪就绪提示**: ready 列中 CI 未通过时，橙色背景警告条
5. **冲突原因标签**: conflict 列中显示具体原因（代码冲突 / CI 失败 / 需变基）
6. **CI 摘要**: 动态颜色背景（running=橙、failed=红、success=绿）
7. **作者 + 分支**: 作者头像+名字，源分支→目标分支（带 Link/ArrowRight 图标）
8. **底栏**: 评论数/变更文件数统计 + 查看详情按钮

#### 验收点

| # | 验收条件 | 预期结果 | 验证方式 |
|---|----------|----------|----------|
| 2.3.1 | 已合并卡片 #8 | 显示绿色 CI 对勾、已合并标签、MR#、Reviewer chip、标题、CI 通过摘要、作者/分支 | 截图验证 ✅ |
| 2.3.2 | 已关闭卡片 #6 | 显示灰色状态点、已关闭标签、标题、作者/分支（无 CI 摘要） | 截图验证 ✅ |
| 2.3.3 | Reviewer chip 颜色 | approved=绿色边框+对勾；changes_requested=红色边框+叉；pending=灰色边框+时钟 | 代码审查 |
| 2.3.4 | 无 Reviewer 提示 | pending_review 列卡片无 reviewer 时显示「未指派 Reviewer」 | 代码审查 |
| 2.3.5 | 冲突原因标签 | conflict 列卡片显示具体冲突原因（红色标签） | 代码审查 |

### 2.4 列头图标增强

**需求**: 每列标题增加语义化图标，颜色与列主题一致。

| 列 | 图标 | 颜色 |
|----|------|------|
| 待 Review | `Clock` | `#909399` |
| Review 中 | `UserFilled` | `#e6a23c` |
| 冲突待解决 | `WarningFilled` | `#f56c6c` |
| 可合并 | `CircleCheckFilled` | `#67c23a` |
| 已合并 | `Select` | `#409eff` |
| 已关闭 | `CircleClose` | `#909399` |

**验证方式**: 页面截图可见图标与文字并排显示，颜色一致 ✅

### 2.5 拖拽交互优化

**需求**: 拖拽时有颜色反馈，且禁止从终态列拖拽。

| 拖拽状态 | 列边框颜色 | 语义 |
|----------|------------|------|
| drag-over-allowed | 绿色 (`#67c23a`) | 允许放置 |
| drag-over-conditional | 橙色 (`#e6a23c`) | 条件放置（如 ready → conflict） |
| drag-over-forbidden | 红色 (`#f56c6c`) | 禁止放置（如 merged/closed） |
| drag-over-terminal | 灰色 (`#909399`) | 终态列（merged/closed）不响应 |

**验证点**:
- `canDrag()` 阻止从 `merged` / `closed` 列拖拽 ✅
- 终态列卡片 `draggable=false` + `is-readonly` 类 ✅
- 各列 CSS 类已定义，待有数据时可直接触发 ✅
